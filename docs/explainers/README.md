# How our gym system works

These pages explain the Jeyo's Hardhit gym management system in plain words, one unit at a time. They are written for everyone on the team, including readers with no programming background. For the full technical detail, see the [plan](../plans/2026-09-15-0946-feat-jeyos-gym-management-system-plan.md).

## How to read them

- Read the pages in order. Each unit builds on the ones before it.
- Each page starts with **Words used on this page**. Look there when a word is new.
- Each page ends with **Check yourself**. Answer the questions before you read the answers. If you can answer all of them, you can explain that unit to the instructor.
